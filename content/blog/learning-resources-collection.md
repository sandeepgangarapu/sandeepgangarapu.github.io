Over the years, I have come across multiple resources I learned things from with ease. This is a page to track those resources. Please [reach out to me](/about/) if you think something belongs to this list. I will add it.

### General

- [Julia Evans](https://wizardzines.com/) has online zines for topics ranging from SQL, Shell scripts to Linux. These are hand-drawn explanations of stuff related to a particular topic. I stumbled upon here twitter post about how SQL actually executes a query and have been a fan ever since.
- All things ML, DS, CS, Stats. This is most comprehensive source I have ever seen.
    
    [https://github.com/Developer-Y/cs-video-courses](https://github.com/Developer-Y/cs-video-courses)
    

### SQL

- [SQL Zoo](https://sqlzoo.net/). Hands down the best place to start learning SQL. This is where I learned from and advised many students to learn from as well.
- [SQL Zines](https://wizardzines.com/zines/sql/). Great resource for getting introduced to SQL. It has clear explanations with awesome visuals.
- Complete overview of SQL in one [page](https://websitesetup.org/sql-cheat-sheet/).

### Python

- [Chris Albon](https://chrisalbon.com/) has a great repository of all things Python Data Science. It's just good to just scroll through and refresh your coding memory.
- [Numpy](http://jalammar.github.io/visual-numpy/) visualized. His blog has other cool visualizations too.
- Dan Bader's [website](https://dbader.org/blog/python-dictionaries-maps-and-hashtables) is a great place to learn python all around.
- Corey Schafer's [YT channel](https://www.youtube.com/user/schafer5). All python concepts are explain clearly.

### Pyspark

- [https://pyspark.itversity.com/03_data_processing_overview/01_data_processing_overview.html](https://pyspark.itversity.com/03_data_processing_overview/01_data_processing_overview.html) is the best I could find on pyspark

### Data Science

- DataCamp is a good place to get started. The career paths with 4-8 hour courses with bite sized videos and in website coding practice is really good and is the best way to get hands on with Data science.

### Causal Inference

- Mastering metrics (Introductory) and Mostly harmless econometrics (Intermediary) are great books to get a intuition of all this econometrics and causal inference. Search amazon.
- [The effect](https://www.amazon.com/Effect-Nick-Huntington-Klein/dp/1032125780/ref=sr_1_3?crid=2VY7DISCVPUO5&keywords=the+effect&qid=1669234209&s=books&sprefix=the+eff%2Cstripbooks%2C525&sr=1-3&ufe=app_do%3Aamzn1.fos.08f69ac3-fd3d-4b88-bca2-8997e41410bb) is another great book. I really admire the author, [Nick HK](https://nickchk.com).

### Machine Learning

- [https://mlu-explain.github.io/](https://mlu-explain.github.io/)
- Machine learning [flash cards](https://machinelearningflashcards.com/) from Chris Albon is a great ML refresher. There are 300 hand-drawn cards explaining concepts related to ML. It costs $12 but is totally worth it. If that is a problem, he shares a card everyday on his [twitter](https://twitter.com/chrisalbon).
- [PCA](https://notsquirrel.com/pca/)
- Sebastian Raschka's [book](https://www.amazon.com/Python-Machine-Learning-Sebastian-Raschka-ebook/dp/B00YSILNL0) is great to get started on coding ML with Python. It's easy to follow and has great code snippets. His [github](https://github.com/rasbt) has good lecture notes.
- Technical ML bible [here](https://deep-learning-drizzle.github.io/index.html#reinf)

### Statistics

- [3blue1brown](https://www.youtube.com/channel/UCYO_jab_esuFRV4b17AJtAw) is the coolest educator I could think of. I learned so much from his videos. His series on linear algebra is my favorite.
- [Eigen Values and Eigen Vectors](http://setosa.io/ev/eigenvectors-and-eigenvalues/). I don't think they update the website anymore. Cool visualizations nonetheless.
- Prof. Charles Geyer (UMN Statistics) has the best slides on Intermediate Theory of Statistics [I](http://www.stat.umn.edu/geyer/5101/), [II](http://www.stat.umn.edu/geyer/5102/).
- Aerin Kim's Medium [blog](https://towardsdatascience.com/@aerinykim) - Very nice intuitive explanations of statistical concepts
- Introduction to Bayesian Data Analysis lecture [series](https://www.youtube.com/watch?v=3OJEae7Qb_o) by Rasmus Baath - An amazing intuitive introduction to Bayesian thinking.
- Course catalogue for [Causal Inference](https://twitter.com/econshishir/status/1356375349337141248?s=20)

### Blogs

- [Rachel Thomas](https://www.fast.ai/topics/#advice) runs a cool blog on all things AI. I really loved her blogs on general advice in the field.
- [Andrew Gelman's blog](https://statmodeling.stat.columbia.edu/) - If you have time to kill. Has some very nice answers to weird and unintuitive questions.
- [https://davegiles.blogspot.com/2019/10/everythings-significant-when-you-have.html#more](https://davegiles.blogspot.com/2019/10/everythings-significant-when-you-have.html#more)
    - This blog is now retired 😢

### Others

- [https://ciechanow.ski/archives/](https://ciechanow.ski/archives/) has great explanations with visualizations of how stuff works at a very fundamental level.

### Typing

- [https://www.typingclub.com/](https://www.typingclub.com/) is a great place to learn how to type. I typed by looking at keyboard for 12 years until I started learning to type. Its a great skill to have and I cannot think of better website to start.
